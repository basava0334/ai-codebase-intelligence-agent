# ai-codebase-intelligence-agent

An AI-powered tool that helps developers understand software codebases by answering questions about code and analyzing project structure.

## Planned features

- Search source code
- Answer questions with relevant file references
- Summarize project structure and dependencies
- Identify complex files and maintenance hotspots

## Status

Project setup
## Run the app on Windows

1. Install Python from [python.org](https://www.python.org/downloads/).
2. Download this project using the green **Code** button, then **Download ZIP**.
3. Extract the ZIP file.
4. Open Command Prompt in the extracted project folder and run:

   ```text
   pip install -r requirements.txt
   streamlit run app.py
      ```

The app will open in your browser.
